# Systeme i18n — Guide

## Langues Supportees

| Code | Langue | Defaut |
|------|--------|--------|
| `fr` | Francais | Oui |
| `en` | English | Non |
| `es` | Espanol | Non |

## Comment ca marche

### 1. Routing

Chaque page est sous `src/app/[locale]/`. Le parametre `locale` est extrait automatiquement :

```tsx
export default async function Page({
  params,
}: {
  params: Promise<{ locale: string }>;
}) {
  const { locale } = await params;
  const dict = await getDictionary(locale as Locale);
  // ...
}
```

### 2. Dictionnaires (UI Strings)

Les fichiers `src/lib/i18n/locales/{fr,en,es}.json` contiennent toutes les traductions UI :

```json
{
  "nav": { "features": "Fonctionnalites", ... },
  "hero": { "title": "Stop Excel.", ... },
  "pages": {
    "industries": { "commonProblems": "Problemes courants", ... },
    "blog": { "backToBlog": "Retour au blog", ... },
    "comparisons": { "whyChoose": "Pourquoi choisir Robi AI ?", ... },
    "featuresPage": { "benefits": "Avantages", ... }
  }
}
```

### 3. Donnees SEO (seo-config.ts)

Les donnees metier (industries, blog, features) sont multilingues dans `src/data/seo-config.ts` :

```ts
{
  slug: "plombier",
  name: { fr: "Plombiers", en: "Plumbers", es: "Fontaneros" },
  title: { fr: "Logiciel de Facturation pour Plombiers", en: "Invoicing Software for Plumbers", es: "..." },
  painPoints: [
    { fr: "Paperasse apres chaque intervention", en: "Paperwork after every job", es: "..." },
  ],
}
```

### 4. Helper `t()`

Pour acceder a la bonne langue depuis seo-config :

```tsx
import { t } from "@/data/seo-config";

// Dans un composant
<h1>{t(industry.name, locale)}</h1>
<p>{t(industry.description, locale)}</p>
```

## Ajouter une Traduction

### Ajouter un texte UI

1. Ajouter la cle dans `fr.json`
2. Ajouter la meme cle dans `en.json` et `es.json`
3. Utiliser `dict.maSection.maCle` dans le composant

### Ajouter une industrie

1. Ajouter l'objet dans `industries[]` de `seo-config.ts`
2. Chaque champ texte doit etre `{ fr: "...", en: "...", es: "..." }`
3. La page sera auto-generee par `generateStaticParams()`

### Ajouter un article blog

1. Ajouter dans `blogPosts[]` de `seo-config.ts`
2. Ajouter le contenu markdown dans `articleContent` de `blog/[slug]/page.tsx`
3. Ajouter la categorie dans `pages.blog.categories` des 3 locales si nouvelle

## Middleware

Le middleware (`src/middleware.ts`) detecte la langue du navigateur via `Accept-Language` et redirige `/` vers `/{locale}`.

> Note : Next.js 16 deprecie `middleware.ts` au profit de `proxy.ts`. Migration a prevoir.
